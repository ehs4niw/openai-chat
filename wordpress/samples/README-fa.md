# اکسل آزمایشی ۳۵ دانش‌آموز با پرونده کامل

تمام داده‌ها ساختگی و صرفاً برای تست هستند؛ از اطلاعات هویتی فایل‌های ارسالی کاربر کپی نشده‌اند. این فایل را به جای ثبت‌نام واقعی استفاده نکنید.

۲۲ ستون استاندارد نسخه ۰.۱۱.۲، ۳۵ حساب آزمایشی تازه، برای سال ۱۴۰۵–۱۴۰۶:

- ۷ نفر دهم ریاضی: class_id=3
- ۷ نفر دهم تجربی: class_id=4
- ۷ نفر یازدهم تجربی: class_id=5
- ۷ نفر دوازدهم ریاضی: class_id=6
- ۷ نفر دوازدهم تجربی: class_id=7

کدهای ملی دانش‌آموز و ولی با رقم کنترل معتبر آزمایشی و به شکل متن‌اند. تمام ۲۲ ستون هویت، تماس، ولی و پذیرش پر است. کد دانش‌آموزی با TEST شروع می‌شود تا حساب تست مشخص باشد. نام کاربری و رمز اولیه طبق افزونه همان کد ملی ستون اول است. در فایل فرمول وجود ندارد.

مدیریت آموزشی ← دانش‌آموزان ← ورود از اکسل؛ سال انتخابی 1405-1406 باشد و شناسه کلاس‌ها مطابق فهرست فوق بماند. ورود اطلاعات حساب موجود را بازنویسی نمی‌کند؛ این داده‌ها برای حساب‌های تازه هستند. تکرار ورود حساب تکراری ایجاد نمی‌کند.

عکس و اسکن مدارک، نمره، شهریه، سوابق حضور و انضباط از اکسل ثبت مشخصات وارد نمی‌شوند؛ فایل مدارک از صفحه پرونده و سایر سوابق از بخش خودشان ثبت می‌شوند.
