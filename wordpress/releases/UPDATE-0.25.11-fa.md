# ۰.۲۵.۱۱ — اصلاح خروجی قدیمی ویجت‌های صفحه معرفی

آیکون‌های قدیمیِ جداگانه ویجت‌ها در محتوای صفحه معرفی پنهان می‌شوند تا فقط آیکون کنار عنوان نمایش داده شود. سه برچسب پایه‌ها روی HTML قدیمیِ ذخیره‌شده نیز ساخته می‌شوند؛ این اصلاح نیاز به بازنویسی صفحه ندارد و با اجرای دوباره برچسب تکراری نمی‌سازد.

کارت معاونت از عرض موجود استفاده می‌کند و چیدمان عمودی با عکس گرد و متن وسط دارد. نام و معرفی مدیر در فضای متنی کارت وسط‌چین شده تا متن کوتاه در لبه کارت جمع نشود. اطلاعات و متن معرفی واقعی حفظ شده و متنی ساختگی اضافه نشده است.

ZIP کامل را جایگزین نسخه قبلی و کش LiteSpeed و فایل‌های CSS المنتور را پاک کنید. آزمون مرورگر روی HTML قدیمی و اجرای دوباره اسکریپت: سه برچسب مستقل و حذف آیکون قدیمی تأیید شد.
