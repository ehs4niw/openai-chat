# فوتر قالب ۰.۱.۴

طرح سوم یاسی، لوگوی کوچک وسط‌چین ۶۴ پیکسل، ارتباط و دسترسی سریع، امضای طراحی و برنامه‌نویسی ehs4niw. نمایش دسکتاپ و موبایل بررسی شد.

نصب: قالب کامل daneshgaran-theme-0.1.4.zip را از نمایش ← پوسته‌ها بارگذاری و جایگزین کنید. یا پچ پنج‌فایلی را در wp-content/themes استخراج و جایگزین کنید. افزونه سامانه تغییر نکرده است.

لوگوی دقیق ارسالی: نمایش ← سفارشی‌سازی ← اطلاعات مدرسه دانشگران ← لوگوی کوچک فوتر؛ همان فایل تصویر دلخواه را بارگذاری یا از رسانه انتخاب کنید. در نبود انتخاب، نمادک فعلی سایت استفاده می‌شود و سپس لوگوی همراه قالب. فایل اصلی تصویر جدید در فایل‌های پروژه موجود نبود؛ نشان پیش‌فرض همان نمادک پیشین است. لوگو و امضای برنامه‌نویس لینک خارجی ندارند.

پس از جایگزینی کش را پاک کنید. نصب زنده انجام نشده است.
