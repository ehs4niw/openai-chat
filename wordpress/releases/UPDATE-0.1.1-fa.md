# اصلاح نمایش قالب دانشگران — ۰.۱.۱

این بسته اصلاح ظاهر قالب است. داده‌ها، برگه‌ها، فرم‌ها و نقش‌ها تغییر نمی‌کنند.
فایل افزونه سامانه دانشگران تغییری ندارد؛ راه‌انداز را دوباره اجرا نکنید.

نشانه مشاهده‌شده: صفحه بدون استایل، لینک‌های آبی و SVGهای بسیار بزرگ.
آزمایش کاربر روی فایل CSS به ERR_CONNECTION_RESET رسید؛ این خطا به معنی ۴۰۴ نیست و علت دقیق اتصال هنوز مشخص نشده است.
در نسخه جدید CSS اصلی همراه HTML صفحه چاپ می‌شود؛ آیکون‌ها هم width/height مستقل دارند.
مسیر تصویر و فونت همچنان به فایل‌های رسانه‌ای نیاز دارد؛ اگر آن‌ها هم قطع شوند، تنظیمات هاست/اتصال باید بررسی شود.

## روش پیشنهادی برای سایت نصب‌شده

۱. ZIP کوچک `daneshgaran-theme-patch-0.1.1.zip` را دانلود کنید.
۲. در cPanel وارد `public_html/wp-content/themes` شوید.
۳. ZIP را همان‌جا Upload و Extract کنید و جایگزینی فایل‌های موجود را تأیید کنید.
این ZIP فقط ۳ فایل دارد: `daneshgaran/functions.php`، `daneshgaran/style.css` و `daneshgaran/assets/site.css`.
این فایل، بسته کامل نصب قالب نیست؛ در بارگذاری پوسته وردپرس نصب نکنید. فقط برای به‌روزرسانی قالب موجود در cPanel است.
۴. در وردپرس، Rocket را یک بار پاک‌سازی کنید؛ اگر حذف CSS استفاده‌نشده فعال است، موقتاً خاموش کنید و کش آن را هم پاک کنید.
۵. صفحه اصلی را با Ctrl+Shift+R و در پنجره ناشناس باز کنید.
۶. در نمایش ← پوسته‌ها ← جزئیات دانشگران، نسخه باید ۰.۱.۱ باشد.

اگر نمی‌خواهید از وصله استفاده کنید، `daneshgaran-theme-0.1.1.zip` بسته کامل قالب است؛ مانند نصب قبلی از cPanel استخراج و فایل‌ها را جایگزین کنید.
افزونه را حذف نکنید؛ برگه‌ها را دوباره نسازید؛ نیازی به تغییر دیتابیس نیست.

## بررسی انجام‌شده

آزمون واقعی روی وردپرس با المنتور فعال: صفحه اصلی و سامانه در عرض ۳۹۰ و ۱۴۴۰.
دریافت فایل خارجی site.css عمداً در مرورگر مسدود شد؛ استایل اصلی داخل صفحه وجود داشت، آیکون‌ها ۲۲ پیکسل بودند و اسکرول افقی ناخواسته دیده نشد.
هدر امنیتی یا تنظیمات Rocket سایت واقعی در محیط محلی بازتولید نشده‌اند؛ رفع نهایی روی سایت کاربر بررسی می‌شود.
