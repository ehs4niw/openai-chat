# قالب‌های مستقل المنتور — صفحه اصلی و معرفی دانشگران

این بسته افزونه یا پچ نیست. فقط محتوای وسط دو صفحه است و سایدبار، نوار بالا و فوتر ندارد. فایل‌ها هیچ صفحه‌ای را خودکار تغییر نمی‌دهند. به Elementor Pro و افزونه دانشگران ۰.۱۹.۰ یا بالاتر نیاز دارد؛ همان افزونه‌ای که گالری تصاویر مدرسه را اضافه کرد. برای این بسته، فایل افزونه جدیدی لازم نیست.

## استفاده

۱. ZIP را روی کامپیوتر استخراج کنید؛ در cPanel یا «افزودن افزونه» نصب نکنید.
۲. در وردپرس ← قالب‌ها / Templates ← قالب‌های ذخیره‌شده / Saved Templates ← درون‌ریزی قالب، فایل JSON دلخواه را انتخاب کنید. از پوشه داخل ویرایشگر المنتور ← قالب‌های من ← درون‌ریزی نیز می‌توانید استفاده کنید.
۳. برای کل صفحه، `home-complete.json` یا `about-complete.json` را وارد کنید. برای یک بخش، فقط فایل مربوط به همان بخش از پوشه home یا about را وارد کنید. قالب کامل و همه بخش‌های همان صفحه را هم‌زمان در برگه نگذارید؛ محتوا تکراری می‌شود.
۴. همان برگه فعلی خانه یا معرفیِ آماده‌شده با المنتور را باز کنید، از طرح فعلی یک خروجی/نسخه پیشین نگه دارید و قالب واردشده را در محل محتوای وسط درج کنید. سایدبار و فوتر فعلی می‌مانند. طرح برگه را روی «پیش‌فرض» بگذارید؛ Elementor Canvas انتخاب نکنید چون پوسته سایت را حذف می‌کند.
۵. یک بار پیش‌نمایش دسکتاپ و موبایل را ببینید، سپس انتشار را بزنید. اگر بعد از انتشار استایل قدیمی ماند، Elementor ← ابزارها ← پاک‌سازی فایل‌های CSS و داده‌ها و سپس کش WP Rocket را پاک کنید. لازم نیست «آماده‌سازی دو صفحه» افزونه را دوباره بزنید.

## ویرایش و اتصال به سامانه

متن، عنوان، عکس بنر، دکمه و لینک‌ها با ویجت‌های قابل ویرایش المنتور ساخته شده‌اند. چیدمان ویژه هر بخش داخل همان بخش، در پیشرفته ← Custom CSS نگه‌داری می‌شود؛ فایل CSS جدا یا تغییر کد افزونه لازم نیست. این CSS به همان بخش محدود است؛ متغیر تصویر مرجع بنر تنها استثنا و صرفاً یک تصویر است. برای تغییر شبکه و فاصله‌های ویژه، Custom CSS همان بخش را ویرایش کنید.

ویجت «اطلاعات زنده دانشگران» اطلاعات عمومی را می‌خواند:

- اساتید و مدیر/معاونت: از پروفایل‌های منتشرشده سامانه؛ عکس، نام، تخصص و رزومه از همان پرونده می‌آیند. مدیر روی انتخاب خودکار تنظیم شده است.
- اخبار: نوشته‌های منتشرشده در دسته‌های `school-news` و `ministry-news`، همراه تصویر شاخص و تاریخ واقعی.
- برگزیده: رکوردهای منتشرشده دانش‌آموز برگزیده در چهار بازه.
- گالری: پیشخوان ← دانشگران ← گالری تصاویر مدرسه ← افزودن تصویر جدید. دکمه مشاهده کامل، آدرس صفحه گالری سامانه را خودکار می‌خواند.
- تماس: از تنظیمات عمومی مدرسه.

اگر اطلاعات یک بخش هنوز منتشر نشده باشد، پیام خالی نمایش داده می‌شود؛ اسامی و تصاویر افرادِ نمونه طراحی به‌عنوان پرونده واقعی وارد نمی‌شوند. کارت‌های امکانات، متن نمونه طرح هستند و باید با امکانات واقعی مدرسه تطبیق داده شوند.

تصویر بنر خانه و معرفی کوتاه، از خود مرجع ارسالی به‌صورت برش نمایشی CSS استفاده می‌کند و داخل JSON جاسازی شده؛ دانلود عکس خارجی لازم نیست. بنر معرفی از تصویر مرجع موجود در افزونه استفاده می‌کند. برای جایگزینی، روی ویجت «تصویر مدرسه دانشگران» بزنید و عکس اصلی را از رسانه انتخاب کنید؛ حالت مرجع کنار می‌رود. عکس‌های اساتید و گالری از رسانه/پرونده‌های سامانه خوانده می‌شوند.

لینک دکمه‌های ثابت برای `daneshgaranedu.ir/index.php/...` تنظیم شده‌اند؛ در صورت تغییر نامک برگه‌ها، لینک دکمه را در المنتور تغییر دهید. اطلاعات پویا و لینک پروفایل‌ها/گالری از سامانه خوانده می‌شوند.

## بررسی انجام‌شده

۱۹ فایل JSON با واردکننده واقعی کتابخانه المنتور وارد شدند و حفظ محتوا و Custom CSS بررسی شد. دو صفحه کامل در وردپرس محلی ذخیره و در عرض‌های ۳۹۵، ۱۰۰۰ و ۱۴۴۰ پیکسل بررسی شدند؛ گالری هر دو صفحه، دکمه مشاهده کامل، عرض ستون توضیح ورود و نبود سرریز افقی بررسی شد. محیط محلی المنتور رایگان داشت؛ برای بررسی بصری، جایگزینی استاندارد selector در CSS پرو شبیه‌سازی شد. اجرای خود Elementor Pro و نصب روی سایت اصلی انجام نشده است.
