اصلاح ظاهر فهرست جستجوی دانش‌آموز در گزارش ماهانه سایت دکتر فرضی.

کد کامل TXT را جایگزین کد اسنیپت موجود با شناسه۴۱ و نام «حساب کاربری — یکپارچه» کنید؛ سپس ذخیره و کش را پاک کنید. اسنیپت جدید ایجاد نکنید. اگر اصلاح جداگانه قبلی فعال است، آن را غیرفعال کنید.

JSON فقط همین اسنیپت را دارد؛ برای ورود از آن تنها در صورت انتخاب جایگزینی اسنیپت موجود استفاده کنید. فایل کامل سایر اسنیپت‌ها در این پوشه منتشر نشده است. تغییر فقط استایل لایه‌بندی و فقط در endpoint ساعت مطالعه است؛ داده‌ها و مجوزها تغییر نمی‌کنند. نحو PHP بررسی شده است؛ روی سایت زنده نصب نشده است.
